# 立冬祝福页 · 2026

三个纯静态、手机优先的立冬祝福页面，无构建步骤，直接由 GitHub Pages 托管。

| 路径 | 名字 | 特点 |
| --- | --- | --- |
| `/` | 立冬 · 愿你三冬暖 | 深蓝星空 + 祝福文字拼成的爱心（canvas 粒子）+ 飘雪 + 拆信弹窗，零外部依赖 |
| `/together/` | 立冬 · 和你一起走到冬天 | 分屏滚动叙事长页：序 → 来路（春/夏/秋）→ 落雪 → 信，零外部依赖 |
| `/card/` | 立冬 · 暖语 | 浅蓝渐变卡片 + 雪花，可点「更换姓名」，也支持 `?to=姓名` 直接预填 |

## 用法

- 直接打开根路径，就是「愿你三冬暖」这一页，适合直接转发。
- 想带上对方名字，用卡片页：`/card/?to=小明`
- 2026 年立冬为 11 月 7 日，`together/` 页面首屏写的就是这一天。
